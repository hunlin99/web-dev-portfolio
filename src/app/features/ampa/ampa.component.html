Project Overview

AMPA is a marketplace concept connecting Afro-diaspora consumers with independent vendors. My scope spans brand identity, consumer and vendor UX flows, mobile interfaces, and responsive web design.

How can one marketplace connect cultural identity with two distinct user experiences?
